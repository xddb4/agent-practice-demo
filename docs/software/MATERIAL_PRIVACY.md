# 作品附件的联系方式脱敏

## 行为

PDF、TXT、Markdown 附件先在后端提取正文。正文或文件名中附带的邮箱、常见中国大陆手机号会替换为 `[邮箱已隐藏]`、`[手机号已隐藏]`，再执行内容检查。上传响应、附件记录中的正文、文件名和后续模型材料均使用脱敏内容；返回提示和替换数量，不返回被移除的值。

这适用于论文作者邮箱、比赛作品封面中的提交者联系方式等附带信息，不依据“是我自己的号码”判断是否放行。功能只需作品内容，不需要模型读取联系方式。

身份证号、银行卡号、密码、验证码等仍触发拒绝；请求提取个人联系方式仍拒绝。普通聊天输入、模型输出和搜索的现有检查不放宽。是否属于敏感内容仍依赖规则检测，不承诺识别所有号码格式或所有个人信息。

## 检查提示与修正

上传后，弹窗显示检测类型和位置，不回显敏感原文或周围句子。PDF 保留提取页分隔，可报告页码及提取正文行号；文本报告提取行号，文件名单独标注。行号可能与原文件视觉排版不同。最多展示20处，拒绝类信息优先，超过时提示检查完整文件。

可自动脱敏的联系方式需要用户确认后才提交 Agent；用户也可取消，回原表单修改或更换文件。上传已完成的原文件仍在账号附件区，取消不会撤销这次上传。必须拒绝的内容会停止提交，提示删除或遮盖后重新导出上传。

即使未命中规则，也会提示检测范围和漏检可能性。PDF、图片另行提示：图片和扫描内容无法可靠检测。不能将“未检测到”写成“没有任何隐私信息”。

## 原文件与历史附件

原始上传文件不被改写，仍保存在后端附件区，仅上传账号可通过现有鉴权下载。**脱敏对象是供分析的提取正文和文件名，不是可下载的 PDF 二进制内容。**上传界面明确说明这一区别。

历史附件被用作推荐材料时，再次执行同样的脱敏与严格检查，防止旧记录中的联系方式进入模型。已有历史数据库记录和原附件不做批量迁移或删除。

## 图片边界

当前服务没有本地 OCR 脱敏流程，图片和扫描 PDF 中的联系方式不能靠正文正则可靠去除。用户应先遮盖图片上的联系方式再上传。不能将“图片上传成功”视为“图片隐私已脱敏”。

姓名、单位、地址、学号、国际电话号码等未被本次规则完整覆盖。与分析无关的信息应先由用户遮盖；需要进一步支持时，应新增有明确上下文的检测规则和针对性测试，避免把论文编号、课程编号、实验数据误判为个人号码。

## 验证

回归用例包括：附带邮箱与多种大陆手机号格式、带邮箱的文件名、论文 PDF、历史附件重新读取、账号隔离、严格拒绝内容，以及前端在脱敏后显示通知。另对用户提供的论文进行本地提取与脱敏复验：移除一处作者邮箱，正文可通过附件检查；未调用真实模型。
