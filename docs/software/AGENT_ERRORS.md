# Agent 错误诊断

2026-11-14，本地对话错误编号 `54fad05489f2` 的日志类别为 `invalid_output`。
旧日志没有保存校验字段。只读重放相同消息，在 16 项任务方案上返回
`changes / too_long`：旧对话输出最多允许 12 项调整，整份方案修改会超限。

对话调整数量现与方案容量一致，最多 100 项。模型收到完整 JSON Schema，
校验失败时最多自动修复一次。截断输出单独报告，不把残缺结果写入数据库。
调整仍需通过任务关联、时间和冲突检查，并由用户确认后应用。

对话失败消息展示标题、原因、具体字段问题、处理建议与错误编号。
模型密钥验证、额度、权限、限流、地址/模型不存在、参数不兼容、超时、连接、
服务商异常、输出截断和输出校验分别归类。浏览器连接不到本地后端与非 JSON
响应另行提示，要求重新打开对话核对请求结果。

`logs/server.warning.log` 记录模型失败的错误编号、类别、异常类型、上游状态和
脱敏校验摘要（字段名称、条目序号和校验类型）。不记录密钥、用户输入、
模型原文或异常原文。服务器 ERROR/CRITICAL 继续写入 `logs/server.error.log`。
日志目录由 Git 忽略，不提交。
