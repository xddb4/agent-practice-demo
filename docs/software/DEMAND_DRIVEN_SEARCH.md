# 按信息缺口联网检索

首次生成推荐与后续方案对话均由模型判断是否需要搜索，不强制联网或凑满资料数量。一般方法、改期和时间预算调整可直接参考已有知识及用户信息；最新考试、比赛规则等需核实的信息定向搜索，优先官方来源。不足时更换关键词补查，依据充分即停止。

每次工具调用必须提交公开关键词、待核验问题和所需结果数（1–5）。每轮最多实际请求 3 次，累计最多 10 条去重链接，搜索请求累计等待预算 30 秒，每次请求超时不超过 12 秒。时间预算仅针对搜索请求，不是整轮模型回复的时间保证。重复关键词复用结果，不消耗新的搜索请求。耗尽预算或检索失败仍可回答，但须明确未核实之处。

检索记录保留关键词、核验目的、返回数量、服务状态与检索时间。只保存服务实际返回的来源，不让模型虚构来源；检索结果不等于已采用依据，也不等于已阅读全文。模型仍须检查来源、主题及适用届次，当前未自动抓取全文或实现独立事实核验。

后续对话的检索结果随对应助手消息保存和展示；原方案的历史参考资料保留原检索时间。搜索工具不接收完整用户画像，提示词明确禁止将个人成绩、身份、私有材料或具体日程发给搜索服务。

未配置或关闭搜索时沿用结构化回答。带图片请求保留原视觉处理流程：因用户自选 API 未必支持视觉与工具混用，这条路径暂不联网，不会伪造参考资料。
