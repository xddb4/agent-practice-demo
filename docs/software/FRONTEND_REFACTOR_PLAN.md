# 前端规范化重构计划

## 约束与基线

- 基线提交：`800f11a34b85e4e8bde90e05da6f90aecff4282f`。开始时 Git 工作区干净。
- 开始时 57 项前端 Node 测试通过，Docker 的 web/db 均健康。
- 保留 React 外壳、同源 iframe、全部原型和扩展交互、接口地址/参数、数据库与持久化协议。
- 不重画 UI，不删除看似过时的实现；原有字符串模板、选择器、事件与样式层叠顺序均建立等价检查。
- 源码备份与原版生成产物保存在仓库外的 `../frontend-refactor-baseline-20261114/`，不包含账户密钥或数据库。

## 修改前检查结果

1. `StudyPilot.html` 混合页面骨架、内联 CSS、WebGL 动效、本地状态和业务函数，难以阅读。
2. `build.mjs` 在构建时替换原型字符串，并按手写列表复制与注入脚本；目录与运行时文件关系不直观。
3. pages/components 内混合页面、业务、请求和动效。`bridge.js` 同时负责网络、会话、保存和报告。
4. `render/recommend/report/closeModal` 等有兼容包装链；本轮不会不加验证地移除包装或更改调用时序。
5. 多处页面选择规则、主题值分散；CSS 层叠和 Canvas 配色均影响实际外观。
6. 单测使用固定路径及源码片段字符串切割，格式化就可能让测试失效，需要改为明确的测试读取助手。

## 实施步骤

1. 保存原始前端、测试及原版构建产物，建立静态与浏览器基线。
2. 新增资源清单、构建工具、格式配置和开发代理，保持现有公共资源 URL；把构建期转换落实到可读源码。
3. 从 HTML 原样提取 CSS、独立动效和工作台代码；在不改变执行顺序及变量作用域的前提下按职责整理。
4. 按 app/layouts/pages/features/components/api/state/utils/styles 组织现有文件；集中页面注册和导航入口，保留原有 render 生命周期。
5. 抽取共用请求/流式传输与状态持久化代码；不改变请求参数、异常含义及保存语义。
6. 增加主题入口，保留原始设计值与层叠顺序；格式化 JavaScript/CSS/HTML，整理注释。
7. 运行原有测试和新增等价性/注册/构建检查；安装依赖并生产构建，在浏览器检查原版与重构版页面及交互。
8. 在保留原 Docker 名称和数据卷的条件下更新本地运行实例；完成目录树、迁移清单、UI 修改入口、验证记录与回退说明。

## 验证边界

- 对页面标记、样式规则、素材、原业务脚本做等价性校验，避免只以“构建成功”认定保真。
- 浏览器检查使用现有界面的导航及无数据副作用操作；新增/编辑/完成等写入验证使用独立测试账号或隔离测试数据，不改用户已有任务。
- 真实模型/搜索请求若未获可用测试配置，不伪造成功结果，明确列为未验证。
- 已知保存可靠性、回收站、后端模型连接测试等历史问题与本轮组织重构分开，不擅改接口或数据库修复。
