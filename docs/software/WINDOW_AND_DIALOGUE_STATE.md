# 窗口与对话状态

本次规则：

1. 普通窗口只在点击窗口外、关闭按钮或 Esc 时退出。鼠标移出不触发退出；
   从窗口内拖动到外部松开不当作点击外部。
2. 输入、选择、附件和滚动位置保留在本次文档内的内存草稿中，按登录账号隔离。
   对话与课表核对保留实际 DOM 节点及事件，普通表单恢复字段值。成功提交的
   表单清理对应草稿，防止重复提交。
3. 本次网页内再次打开个性化推荐，恢复最近查看的对话、未发送输入、附件和
   阅读位置。显式“新对话”创建独立窗口状态。刷新后内存状态清空，默认进入
   新对话；历史对话及后台任务仍在服务器保留，不依赖浏览器本地存储。
4. 对话生成不依赖窗口是否可见，完成后不强行打断用户当前窗口。页面显示
   后台生成状态入口，打开推荐可查看后台记录。主动停止仍需通过原请求的
   取消接口，取消与保存由事务检查决定。

此改动有意更新了前端重构时冻结的业务脚本和 CSS 基准，保留了未变脚本、
页面骨架、React 壳与图片的原基准。功能验证见 `frontend_modal_drafts.test.cjs`
和 `test_dialogue_stream.py`（包含实际 HTTP 断连后继续生成并恢复结果的测试）。
