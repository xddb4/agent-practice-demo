# StudyPilot 的记忆与方案复用

更新：上下文采用有界摘要，最多40条未完成任务、12条已接受证据、20条显式参考方案任务，并对传给模型的内容设置12000字符硬上限。原始任务和证据不被截断修改；排程器在本地独立读取完整固定安排，避免摘要省略日程导致建议冲突。

推荐页提供无损压缩、归档、恢复、删除记录和清理入口。无损压缩使用可恢复的数据压缩，不让模型改写事实。清理先预览数量并确认，只处理未被正式任务引用的旧识别记录及归档方案，默认30天以前并保留最近5条。任务、能力证据和附件不在清理范围。

当前实现使用按账号隔离的数据库记录，不依靠模型自行记住之前的调用，也没有训练个人模型。

- 一次工作流内：消息列表保留本次目标、工具调用及工具返回结果，调用结束后不自动续接为长期聊天。
- 每次生成：从数据库重新读取当前任务与“已接受”的能力证据。撤回证据后，下次读取即不再纳入；待确认、拒绝和待观察材料不能作为正式能力结论的依据。
- 历史方案：候选、逐项修改、来源与检索时间保存在当前账号的run记录中。推荐页的“我的准备方案”可查看；只有明确点击“作为生成参考”后，选中的方案内容才加入下次Agent上下文。本次目标和约束优先于旧方案。

## 三种复用方式

1. 查看／继续采纳：重新打开已有方案，已加入的条目会标记并排除，未采纳项可以继续修改。每个条目保存稳定的原始索引，避免部分采纳后把内容关联错位。
2. 复用为新方案：创建独立副本，清空旧日期与时段，补齐本次安排后确认。不会自动复制旧任务到日程。
3. 作为生成参考：选中旧方案，再在目标表单调整本次截止日期、可投入时间和基础约束；新的生成会重新读取当前画像和日程，并按实际调用重新检索来源。

历史来源保留当时检索时间，打开或复制不会伪装成刚刚联网核实。旧版本记录若没有生成时间，显示“时间未记录”。历史列表当前最多显示最近50份。

所有读取、复制和选作参考均检查数据归属。相同方案条目在同一任务快照内不能重复采纳；多标签页并发版本控制仍属于后续数据库改造范围。

## 课表图片

打开课表图片窗口，可选择文件或按Ctrl+V粘贴剪贴板截图。PNG/JPEG/WebP，10MB以内。粘贴仅准备预览，点击“识别并核对”才会将图片经后端发送给当前视觉模型。示例课表先转换为PNG，再走同样的真实视觉识别流程，不再返回固定识别结果。
