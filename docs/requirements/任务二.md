### 4 解决方案与核心工作流

1. 目标与约束采集：通过对话获取目标 截止日期 固定日程 可用时间 精力偏好和当前能力基线。
2. 任务结构化：将目标拆解为项目 里程碑 任务和最小行动 并估算时长 依赖与风险。
3. 四象限分类：综合重要性 紧急性 截止日期 影响范围和用户偏好进行分类 用户可调整。
4. 日计划生成：将任务分配到具体日期和时段 保留休息 缓冲与突发事项空间。
5. 执行提醒与反馈：记录完成度 实际耗时 难度 精力和阻碍原因。
6. 能力画像更新：把任务成果作为证据 更新知识技能 通用能力和自我管理指标。
7. 周期复盘与重排：每日微调 每周复盘 每月评估目标与能力方向。

### 6 能力维度与指标体系

能力画像遵循“可观察 可记录 可比较 可解释”的原则。得分不代表对个人的最终评价，而用于帮助用户发现投入结构和变化趋势。建议以 0 至 100 分呈现，并同时显示证据数量 最近更新时间和置信度。

| 能力维度 | 建议指标                             | 数据来源                   | 示例解释                           |
| -------- | ------------------------------------ | -------------------------- | ---------------------------------- |
| 专业知识 | 知识点掌握率 测验正确率 概念复述质量 | 测验 课程任务 用户自评     | 反映对领域知识的理解与迁移         |
| 实践技能 | 任务完成质量 操作熟练度 作品数量     | 项目成果 代码 文档 作品    | 反映把知识转化为成果的能力         |
| 研究能力 | 问题定义 文献检索 证据分析 实验设计  | 论文笔记 研究任务 阶段评审 | 适用于科研 竞赛和深度学习          |
| 沟通协作 | 反馈及时率 会议贡献 协作任务完成度   | 团队记录 同伴反馈 用户自评 | 反映表达 协调与协作可靠性          |
| 问题解决 | 独立解决率 方案数量 复盘深度         | 任务日志 问题单 复盘记录   | 反映面对复杂或不确定问题的处理能力 |
| 时间管理 | 计划完成率 估时偏差 深度工作时长     | 计划与实际时间记录         | 反映安排 执行与调整能力            |
| 自我调节 | 连续执行率 情绪精力记录 恢复速度     | 打卡 自评 复盘             | 反映坚持 自我监控与恢复能力        |

### 7 四象限处理规则

| 象限         | 判断原则                           | 系统建议                                 | 典型示例                    |
| ------------ | ---------------------------------- | ---------------------------------------- | --------------------------- |
| 重要且紧急   | 影响核心目标且临近截止或已造成阻塞 | 立即安排 明确完成标准 必要时拆分并预警   | 明日考试复习 当天项目故障   |
| 重要不紧急   | 对长期目标影响大但仍有时间窗口     | 优先预约固定时段 设置里程碑 防止拖成紧急 | 能力学习 论文准备 健身      |
| 不重要但紧急 | 时间敏感但对核心目标贡献低         | 委派 批处理 限时完成或降低质量门槛       | 一般性通知 临时资料整理     |
| 不重要不紧急 | 影响低且无明确时限                 | 删除 延后或设置娱乐边界                  | 无目的刷信息 重复低价值整理 |

### 8 同类产品与差异化方案

- 与日历产品相比：StudyPilot 不只安排时间，还解释任务为何被安排以及它关联哪项能力。
- 与待办产品相比：StudyPilot 强调目标拆解、时长估算、精力约束和动态重排，而不是静态清单。
- 与通用 AI 助手相比：StudyPilot 维护长期结构化状态，包括目标、任务、计划、实际执行和能力证据。
- 与学习分析产品相比：StudyPilot 面向用户主动规划，支持跨课程、跨项目和个人生活的统一管理。
