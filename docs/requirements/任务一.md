## 任务一 产品使命口号与策略

### 1 产品使命与口号

使命：帮助本科生规划科研任务，实现科研素养成长。

口号：看见成长，规划未来


### 2 目标用户分析


本产品主要面向处于科研入门阶段的本科生。这一群体往往需要兼顾课程学习、文献阅读等多类任务，在判断任务优先级、合理分配时间方面缺乏经验；同时，由于缺少持续反馈，也难以准确了解自身科研素养的发展状况。StudyPilot 旨在帮助他们梳理任务优先级、制定切实可行的计划，为科研素养评估提供可追溯的证据，帮助用户认识自身优劣、看见成长，逐步建立自信。


### 3 用户争取策略

(1)提供计划模板，即点即用，降低用户使用门槛。

(2)建立连续反馈，记录每日完成情况、阻碍并进行复盘，更新素养评估报告，让用户看见投入与成长的关联。

(3)可调整可解释性，以用户的需求和对任务优先级的判断为主，仅提供更改建议，不强制修改。

(4)个性化成长评估，从0开始建立对用户的科研素养评估，实时跟踪，满足个性化需求。

(5)注重隐私与效率提升，产品严格遵守隐私协议，界面简洁直观，不搭载其他冗余功能，提升用户专注力。

### 4 团队优势

- 五人小组规模适合快速分工与交叉评审，可覆盖产品、算法、开发、设计和测试等关键工作。
- 团队来自真实学习场景，能直接观察本科生课程、竞赛、科研和生活等多目标并行的时间管理问题。
- 产品创新点清晰：不是增加一个待办工具，而是把任务优先级、时间计划和能力成长指标统一到同一套数据结构中。
- 可采用轻量原型和小规模用户测试快速验证，降低早期开发成本与方向性风险。

### 5 竞争对手与差异化竞争

#### 样例产品功能对比

| 产品特性             | 番茄 ToDo | NeuroPlan |  |StudyPilot
| -------------------- | :-------: | :-------: | :--------: |
| 科研素养判断             |          |    √    |     √     |
| 任务优先级排程和规划 |    √    |    √    |     √     |
| 科研素养提升追踪         |    √    |          |     √     |

从样例对比可以看出，三款产品均支持任务优先级排程和规划；NeuroPlan 与研时支持能力判断，番茄 ToDo 与研时支持能力提升追踪。StuduPilot在该样例的三个维度上覆盖最完整。StudyPilot需要进一步突出能力指标可视化、任务与能力证据关联以及动态日计划调整，形成区别于现有产品的完整成长闭环。



### 6 SWOT 分析

| 类别               | 关键内容                                                                                                 | 策略含义                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Strengths     | 能力维度可视化形成明确创新点；时间主线与四象限方法易理解；五人团队沟通链路短；可通过对话降低规划成本。   | 聚焦本科生科研成长场景，以计划、证据、能力评估和建议的闭环建立差异。   |
| Weaknesses    | 早期数据少，能力评估准确性有限；小团队开发与运营资源有限；用户长期留存仍需验证。                         | 先做个人计划，再建立六维能力指标与证据链；采用可解释规则与大模型辅助。 |
| Opportunities | 生成式 AI 降低个性化规划成本；高校重视学习过程和综合能力；用户对自我量化与个人成长关注增加。             | 与课程实验、科研训练和竞赛场景合作，形成可复用案例和校园渠道。         |
| Threats       | 大型日历、待办和 AI 产品可快速复制部分功能；隐私与算法建议失误可能降低信任；模型服务成本与稳定性不确定。 | 建立解释机制与专属数据模型；采用模型可替换架构并设置成本预算和人工兜底。 |
