## 任务一 产品使命、口号与策略

### 1 产品使命与口号

使命：帮助学生规划科研学习任务，实现科研学习素养成长。

口号：看见成长，规划未来


### 2 目标用户分析


本产品主要面向处于科研学习入门阶段的学生。这一群体往往需要兼顾课程学习、文献阅读竞赛实践等多类任务，在判断任务优先级、合理分配时间方面缺乏经验；同时，由于缺少持续反馈，也难以准确了解自身科研学习素养的发展状况。StudyPilot 旨在帮助他们梳理任务优先级、制定切实可行的计划，为科研学习素养评估提供可追溯的证据，帮助用户认识自身优劣、看见成长，逐步建立自信。


### 3 用户争取策略

(1)提供计划模板，即点即用，降低用户使用门槛。

(2)建立连续反馈，记录每日完成情况、阻碍并进行复盘，更新素养评估报告，让用户看见投入与成长的关联。

(3)可调整可解释性，以用户的需求和对任务优先级的判断为主，仅提供更改建议，不强制修改。

(4)个性化成长评估，从0开始建立对用户的科研学习素养评估，实时跟踪，满足个性化需求。

(5)注重隐私与效率提升，产品严格遵守隐私协议，界面简洁直观，不搭载其他冗余功能，提升用户专注力。

### 4 团队优势

(1)五人小组分工明确，可交叉评审，覆盖产品、算法、开发、设计和测试等关键工作。

(2)idea来源于真实场景，可提供丰富现实使用场景，反复优化，贴合学生科研学习入门实际。

(3)创新点清晰，将优先级判断，任务规划，素养评估整合到同一平台，

(4)采用轻量原型和小规模真人测试验证，开发成本低。

(5)评估标准科学，论文为素养评估提供判断依据。

### 6 SWOT 分析

| 类别          | 关键内容                                           | 策略含义                                            |
| ------------- | ---------------------------------------------------| --------------------------------------------------- |
| Strengths     | 素养维度可视化；时间主线与四象限直观；团队沟通方便      | 聚焦学生科研学习成长痛点，建立计划、素养评估和建议的闭环  |
| Weaknesses    | 早期数据少，评估准确性有限；团队资源有限；用户黏性待验证| 先做个人计划，再依托论文并采用大模型辅助评估 |
| Opportunities | 生成式AI降低个性化规划成本；高校重视学习过程和综合能力；学生参与科研学习人数增加| 关注现实科研学习场景，形成可复用案例和校园渠道。   |
| Threats       | 功能易被复制；算法建议失误可能降低用户信任度；模型服务不确定 | 采用模型可替换架构并设置成本预算和人工兜底。 |
