## 任务一 产品使命口号与策略

### 1 产品使命与口号

使命：帮助本科生把有限时间转化为有证据、可解释、可持续的科研能力成长。

口号：看见成长 规划每一天

使命强调产品最终创造的用户价值，而不是单一功能。口号将“能力可视化”和“以时间为主线”压缩为便于记忆的表达，既体现成长结果，也体现每天可执行的行动路径。

### 2 目标用户

| 用户群体         | 典型场景                                   | 主要痛点                                                     | 优先级   |
| ---------------- | ------------------------------------------ | ------------------------------------------------------------ | -------- |
| 本科生           | 科研入门、课程实验、论文阅读、竞赛与生活任务并行 | 任务来源分散；难以判断优先级；时间投入与科研能力成长之间缺少证据反馈 | 核心     |
| 青年职场人       | 项目交付、职业学习、证书考试和个人生活协同 | 目标多但时间碎片化；计划易失真；缺少长期能力画像             | 后续拓展 |
| 自我提升型用户   | 语言、编程、阅读、健身等长期目标           | 热情驱动但难持续；里程碑模糊；复盘缺乏量化依据               | 后续拓展 |
| 高校教师与辅导员 | 科研指导、发展辅导、阶段复盘               | 需要了解学生的计划执行与能力变化；进度共享能力留待后续验证   | 潜在合作 |

### 3 用户争取策略

切入高频刚需：以“科研入门周计划”“课程实验计划”“论文阅读计划”“竞赛准备计划”等模板降低首次使用门槛。

呈现首日价值：用户能在 3 分钟内输入一个目标，并得到包含固定任务时间轴和非固定任务建议时段的当天计划；系统不能生成固定时间冲突。能力基线评估在后续分步完成，不作为首次规划的前置条件。

建立连续反馈：记录每日完成度、时长、阻塞点与复盘，结合阶段作品和经用户确认的提取证据更新能力报告，让用户看见投入与成长的关联；不把完成任务或打卡直接等同于能力提升。

校园种子增长：通过课程小组、实验室、学生社团和竞赛团队招募本科生种子用户，以真实科研成长案例带动传播。

可解释与可调整：每条计划展示优先级理由、预计时长和关联能力，允许用户调整并保留修改偏好。每项推荐还应说明接受后对计划的影响，必须经用户认同后才加入正式计划；优先级修改仅作为偏好信号，不能直接改变能力分数。

隐私换信任：默认最小化采集敏感信息，提供数据查看、导出与删除入口，明确用户拥有最终控制权。

### 4 团队优势

- 五人小组规模适合快速分工与交叉评审，可覆盖产品、算法、开发、设计和测试等关键工作。
- 团队来自真实学习场景，能直接观察本科生课程、竞赛、科研和生活等多目标并行的时间管理问题。
- 产品创新点清晰：不是增加一个待办工具，而是把任务优先级、时间计划和能力成长指标统一到同一套数据结构中。
- 可采用轻量原型和小规模用户测试快速验证，降低早期开发成本与方向性风险。

### 5 竞争对手与差异化竞争

#### 样例产品功能对比

| 产品特性             | 番茄 ToDo | NeuroPlan | 研时 |
| -------------------- | :-------: | :-------: | :--------: |
| 能力判断             |          |    √    |     √     |
| 任务优先级排程和规划 |    √    |    √    |     √     |
| 能力提升追踪         |    √    |          |     √     |

从样例对比可以看出，三款产品均支持任务优先级排程和规划；NeuroPlan 与研时支持能力判断，番茄 ToDo 与研时支持能力提升追踪。研时在该样例的三个维度上覆盖最完整。研时需要进一步突出能力指标可视化、任务与能力证据关联以及动态日计划调整，形成区别于现有产品的完整成长闭环。

说明：以上比较按典型产品能力归纳，具体功能会随版本变化。研时的竞争重点不是覆盖所有日历或项目管理功能，而是强化“能力指标—任务—时间—反馈”的闭环。

### 6 SWOT 分析

| 类别               | 关键内容                                                                                                 | 策略含义                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 优势 Strengths     | 能力维度可视化形成明确创新点；时间主线与四象限方法易理解；五人团队沟通链路短；可通过对话降低规划成本。   | 聚焦本科生科研成长场景，以计划、证据、能力评估和建议的闭环建立差异。   |
| 劣势 Weaknesses    | 早期数据少，能力评估准确性有限；小团队开发与运营资源有限；用户长期留存仍需验证。                         | 先做个人计划，再建立六维能力指标与证据链；采用可解释规则与大模型辅助。 |
| 机会 Opportunities | 生成式 AI 降低个性化规划成本；高校重视学习过程和综合能力；用户对自我量化与个人成长关注增加。             | 与课程实验、科研训练和竞赛场景合作，形成可复用案例和校园渠道。         |
| 威胁 Threats       | 大型日历、待办和 AI 产品可快速复制部分功能；隐私与算法建议失误可能降低信任；模型服务成本与稳定性不确定。 | 建立解释机制与专属数据模型；采用模型可替换架构并设置成本预算和人工兜底。 |
