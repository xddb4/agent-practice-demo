# 非功能需求规范

## 1.性能需求：
需保持渲染，页面渲染效果打开速度不超过3秒。用户主动提交的任务须有实时性，智能体通过输入分解任务时间不超过5s，任务推荐1min左右，个性化分析3分钟以内。

## 2.数据安全需求
通过用户的邮箱账密确保用户登录安全，每个用户之间的数据分开存储，保证各用户的任务与分析的隐私。

数据一旦输入即刻存储进入云端，防止用户因断网等以外数据丢失

## 3.简易性设计
所有可输入窗口都可使用智能体辅助识别用户的输入，降低用户叙述需求的负担，不确定处提示用户确认

## 4.页面设计
页面仅主页面（每日计划加四项任务分类方块，且可换出日历），日程输入，用户分析三大页面，使得清晰简易。

## 5.拓展性设计
保留skill商城，供后续迭代使用
