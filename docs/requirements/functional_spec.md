# 功能需求规范

## 1. 用户登录
用户通过邮箱号与密码登录。

## 2.日程录入
用户可以录入课程表，一段文字（文字可包括信息通知，比赛说明等）通过智能体识别，录入系统，用户也可以自己添加日程。

## 3. 四项时间规划

智能体先根据输入自动判别分类，再右侧显示四个独立小方块：重要且紧急、重要不紧急、不重要但紧急、不重要不紧急。每个方块显示任务数量、最近 DDL 和任务摘要。在“重要且紧急”做渲染加强区分。用户可以自行在系统自动判别后选择更改任务类别。

## 4. 每日计划

计划页面左侧呈现每日计划，绑定真实日历ISC，可通过日历查看每天的日程。

左侧上部以课表或时间轴展示固定时间点任务，包含开始时间、结束时间、地点、重复规则和四项标签。在此类任务录入时，系统会判定此时间段是否与之前录入过的固定时间点任务时间冲突，让用户选择去留或均保留。

左侧下部以条目展示非固定任务，包含完成状态、DDL、预计时长、建议时间、能力关联、四项标签和完成标准。

固定任务按开始时间排序；非固定任务默认按 DDL 从近到远排序，相同 DDL 时按四项优先级排序，再按预计时长排序。在用户调整四项分类时跟随一起更改，在用户选择任务完成时，在每日计划与四项界面处均呈现“划去”的渲染。

## 5. 能力报告

智能体会根据用户完成任务的效率，完成偏向，完成度，对用户的能力与行为关联

使用六个能力维度：问题发现与研究设计、计算与系统思维、实验验证与数据素养、批判性与独立思考、信息素养与学术规范、表达协作与反思。

报告应显示能力水平、趋势、置信度、证据数量、主要证据和下一步建议。能力可以用数值、等级或定性描述表达，不强制所有维度使用 0-100 分。

系统支持记录行为、上传或粘贴阶段作品、论文结果和用户自述，并可接收外部反馈。系统先生成候选证据，用户可以接受、修改、拒绝或标记为待观察；未经确认的证据不能更新正式报告。

## 6. 个性化推荐

用户输入比赛，论文，考核等具有长期自由度的准备型任务时。智能体根据对用户的能力记录与评估，联合web search的建议，对用户给出定制化方案，用户选择采纳与否，加入日程。
