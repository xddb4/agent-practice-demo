# 用户模型 API 配置

个人空间右上角“模型 API 设置”与退出登录并列。未配置时使用 Agent 会打开同一设置面板，原输入保留；保存后关闭面板，再次点击原功能按钮。

可选择 DeepSeek、Qwen、OpenAI 或其他 OpenAI 兼容 HTTPS 接口。服务商与模型名称均由用户确认；预填名称仅是候选，不代表账户一定有访问权限。支持填写独立的视觉模型名称。普通文本模型不能自动获得图片能力。

“保存配置”只存储配置，不产生模型调用。“保存并测试连接”先保存，再发送简短文本测试请求，可能产生少量调用费用；连接成功不代表视觉、工具调用或结构化输出已通过完整验证。

配置按登录账号隔离。密钥经 Fernet 加密后存入后端数据库，读取接口只返回是否已配置，浏览器不保存密钥。输入框留空可保留原密钥；更换服务商或 API 地址必须重新输入。密钥不会放入模型提示词、历史记忆或错误响应。

本地加密主密钥在 `.model-encryption.key`，已排除 Git 与 Docker 构建；备份数据库时需要同时妥善备份此文件。它仍位于本机，能读取数据库及主密钥的操作系统用户可以解密，因此这不是针对本机管理员的隔离。Docker Compose 使用附件持久化卷中的 `/app/uploads/.model-encryption.key`，该文件无下载记录，不能经附件 API 访问。

网页 Agent 必须使用当前账号的配置，不回退到 `.env` 中的调试密钥；`.env` 仍可供命令行验证脚本使用。切换模型不影响已保存的任务、证据与历史方案。推荐流程只在所选服务具备已接入的检索能力时查询网络，其他服务会明确显示未配置检索。

接口：GET/PUT/DELETE `/api/model-settings`；POST `/api/model-settings/test`。均需登录。配置对下一次请求生效，不改变已开始的模型请求。
